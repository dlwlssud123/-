## 문제 인식
팀플을 몇 번 하다보니 굉장히 뛰어난 협업 툴이 많다는 것을 느꼈다. 문서 작업 할 때는 Notion, 피피티나 액셀 작업은 Google workspace 등 뛰어난 툴이 많다. 다만 너무 많다. 그래서 굉장히 귀찮다. 
노션을 사용하면 좋다. 잘 사용한다는 가정 하에 한 페이지에서 거의 대부분의 작업을 완료할 수 있으니까. 반대로 말하면 잘 모르면 쓰기 어렵다는 얘기다. 
핵심은 이거다. 사용자가 협업 환경을 직접 설계해야 한다는 것. <- 굉장히 귀찮다. 
그래서 본 프로젝트가 제안하는 것은 **Zero-Setup** 팀플 서비스이다. 좋은 도구들은 이미 많지만, 대학생이 단기 팀 프로젝트 하나를 위해 여러 협업 도구를 학습하고 협업 환경을 직접 구성해야 한다.
우리는 이 문제를 해결하기를 원한다. 별도의 프로젝트 관리 지식이나 협업 도구에 대한 사전 지식 없이도 대학생이 팀 생성 즉시 체계적인 팀 프로젝트를 시작하고 관리할 수 있는 웹 기반 협업 환경을 제공한다.
## 해결 방법
우리가 제안하는 서비스는 기존의 서비스를 완전히 대체하는 서비스가 아니다. 우리 사이트를 협업의 출발점으로 사용한다는 것이 핵심이다.

우리의 프로젝트는 제공한다.
- 팀 생성/초대
- 업무 생성/담당자/마감일
- 업무 진행상태
- 회의 가능시간 조사 및 확정
- 프로젝트 일정
- 작업 완료 보고
- 결과물 링크 연결
- 최근 팀 활동
- 외부 작업 공간 링크 관리

이런 서비스는 기존의 훌륭한 서비스를 사용한다
- 문서 편집기 -> 구글 Docs / Notion 사용
- 프레젠테이션 제작 -> Google Slides 사용
- 클라우드 파일 저장소 -> 구글 드라이브
- 개발 환경, 형상 관리 -> 깃 및 깃허브
- 화상 회의 -> google meet/zoom 사용

## 독창성/차별성
우리가 제공하는 서비스를 하나하나 뜯어보면 기존에 다 있는 훌륭한 서비스이다. 하지만 이걸 사용하기 쉽게 하나로 모아놓은 서비스는 없다. 우리는 이 점을 파고든다. 하나의 페이지에서 프로젝트 계획과 역할 분담, 업무 관리, 작업기한, 일정 관리, 회의 조율, 진행 상황등을 관리하고 실제 작업은 외부의 서비스를 사용하는 것이다.
외부의 서비스로 이동하더라도 작업의 시작과 끝은 우리의 사이트에서 확인된다. 

## 기대효과
여러 사이트를 왔다갔다하면 솔직히 말해서 ADHD 올거같다. 정신 개사나움. 우리는 이런 문제점을 해결해서 대학생들이 온리 작업에만 집중할 수 있게 도와준다.
